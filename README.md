# 내 카드 혜택 (Card Benefit Finder)

보유한 신용카드들의 혜택과 전월실적 조건을 로컬 DB에 저장해두고, 검색/조회할 수 있는 안드로이드 앱입니다.

## 기술 스택
- Kotlin + Jetpack Compose (Material3)
- Room (SQLite) — 카드/혜택 데이터를 기기 로컬 DB에 저장
- Navigation Compose

## 프로젝트 열기
1. Android Studio (최신 안정 버전 권장)에서 `CardBenefitFinder` 폴더를 **Open**으로 엽니다.
2. 이 프로젝트에는 Gradle Wrapper(`gradlew`)가 포함되어 있지 않습니다. Android Studio가 처음 열 때
   "Gradle wrapper가 없습니다" 또는 유사한 안내가 뜨면 제안대로 wrapper를 생성하거나,
   Android Studio에 내장된 Gradle로 동기화(Sync)를 진행하면 됩니다.
3. Gradle Sync가 끝나면 에뮬레이터나 실제 기기에서 Run 하면 됩니다. (minSdk 26 / targetSdk 34)

이 프로젝트는 네트워크가 제한된 환경에서 작성되어 실제 Gradle 빌드까지는 검증하지 못했습니다.
Android Studio에서 Sync 후 오류가 발생하면 오류 메시지를 알려주시면 바로 고쳐드리겠습니다.

## 화면 구성
- **내 카드**: 보유 카드 목록 (카드사, 카드명, 연회비)
- 카드를 탭하면 **카드 상세** 화면에서 해당 카드의 모든 혜택과 조건을 확인
- **혜택 검색**: 카드명/카드사/혜택명/키워드로 전체 카드의 혜택을 가로질러 검색

## 내장된 초기 데이터 (앱 최초 실행 시 자동으로 채워짐)
- 삼성카드 THE iD. PLATINUM(포인트)
- 삼성카드 아시아나 삼성 지앤미 플래티늄
- 신한카드 Mr.Life

각 카드의 혜택/전월실적 조건은 카드사 공식 홈페이지와 뱅크샐러드·카드고릴라·나무위키 등 공개된
카드 비교 정보를 참고해 정리했습니다. 삼성카드 공식 홈페이지는 자동 조회가 막혀있어(robots.txt)
일부 항목은 비교 사이트 정보로 보완했고, 그런 항목은 `conditionDetail`에
"정확한 전월실적 조건은 카드사 홈페이지 확인 필요"라고 표시해 두었습니다.
실제 사용 전에는 카드사 공식 홈페이지나 카드 뒷면 안내로 최신 조건을 한 번 더 확인하시길 권장합니다.

## 데이터 구조 (Room)
- `cards` 테이블: 카드사, 카드명, 연회비, 홈페이지 URL, 메모
- `benefits` 테이블: 카드에 연결된 혜택 1건 (분류, 혜택명, 적립/할인율, 전월실적 최소금액,
  세부조건 텍스트, 월 한도, 참고사항) — `cardId`로 `cards`를 참조 (카드 삭제 시 혜택도 함께 삭제)

## 카드/혜택 직접 추가하기
현재 버전은 초기 데이터만 자동으로 채워지고, 화면에서 새 카드나 혜택을 추가하는 입력 UI는
포함되어 있지 않습니다. 가장 빠르게 카드를 추가하는 방법은 아래 둘 중 하나입니다.

1. `app/src/main/java/com/zeta0707/cardbenefit/data/SeedData.kt` 에 새 `Card`와 `Benefit`을
   추가하고, 기기에서 앱을 삭제 후 재설치(재설치해야 DB가 새로 만들어지며 시드 데이터가 다시 채워짐).
2. (확장) `CardRepository.addCard()` / `addBenefit()`을 호출하는 입력 화면을 추가로 만들면
   앱 안에서 바로 카드/혜택을 추가·수정할 수 있습니다. 필요하시면 이어서 만들어 드릴 수 있습니다.
